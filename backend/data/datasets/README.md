# Bundled benchmark datasets

`early_stage_diabetes.csv` is the UCI Machine Learning Repository's
**Early Stage Diabetes Risk Prediction** dataset (dataset ID 529), downloaded
unchanged from `diabetes_data_upload.csv` on 2026-09-04.

- Source: https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset
- DOI: https://doi.org/10.24432/C5VG8H
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Citation: Islam, M. M. F., Ferdousi, R., Rahman, S., & Bushra, H. Y.
  (2020). *Early Stage Diabetes Risk Prediction* [Dataset]. UCI Machine
  Learning Repository.

The benchmark contains de-identified questionnaire signs and symptoms from
520 people. Q-TRACE uses it only as a research benchmark. It is not a clinical
screening instrument, and a model output is not a diagnosis or treatment
recommendation.
